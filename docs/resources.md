# 6장 - 참고 자료와 다음 단계

![추천 워크숍 자료와 다음 학습 단계를 함께 준비하는 Copilot 코딩 에이전트 팀](assets/fleet.png)

이슈 작성, Copilot에 할당, 초안 PR 검토, 댓글을 통한 반복 개선, 병합까지 AI 네이티브 개발의 전체 과정을 완료했습니다. 아래 링크를 활용해 워크숍 이후에도 역량을 계속 키워 보세요.

## GitHub Copilot과 에이전트

- [Awesome Copilot](https://awesome-copilot.github.com/) - 실무에서 Copilot을 활용할 수 있도록 선별한 예제, 도구, 패턴 모음입니다.
- [Awesome Copilot Learning Hub](https://github.com/github/awesome-copilot) - Copilot App, Copilot Chat, Copilot CLI, 사용자 지정 지침, 스킬, 에이전트 워크플로를 다루는 체계적인 커뮤니티 학습 자료입니다. 2장을 마친 뒤 이어서 살펴보기 좋습니다.
- [GitHub Spec Kit](https://github.github.com/spec-kit/index.html) - Copilot 같은 에이전트가 구현에 활용할 명세를 작성하는, 명세 기반 개발용 도구 모음과 방법론입니다.
- [GitHub Agentic Process Engineering(git-ape)](https://azure.github.io/git-ape/) - 반복 가능한 에이전트 중심 소프트웨어 워크플로를 설계하기 위한 프레임워크 안내입니다.
- [bradygaster/squad](https://github.com/bradygaster/squad) - 여러 에이전트가 팀을 이루는 "Squad" 오케스트레이션 패턴을 실제 코드로 보여 주는 예제 프로젝트입니다.
- [Copilot CLI Fleet 문서](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/fleet) - Copilot CLI 에이전트 워크플로를 조율하고 확장하는 방법을 설명하는 공식 문서입니다.
- [GitHub Copilot CLI 설치](https://docs.github.com/en/copilot/how-tos/set-up/install-copilot-cli) - 2장의 Copilot Chat 및 CLI 탐색 단계에서 사용하는 CLI의 설치 안내입니다.
- [Copilot 코딩 에이전트 소개](https://docs.github.com/en/copilot/concepts/agents/cloud-agent/about-cloud-agent) - 클라우드 코딩 에이전트의 동작 방식과 안전장치에 관한 핵심 개념을 설명합니다.

## 학습과 자격증

- [GitHub Actions 워크숍(GH-AW)](https://github.github.com/gh-aw/) - AI 네이티브 개발 과정과 함께 활용하기 좋은 자동화 패턴을 익히는 실습 자료입니다.
- [Microsoft Agentic AI Developer 자격증](https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-developer/?practice-assessment-type=certification) - 에이전트형 AI 개발 역량을 인증받는 과정입니다.
- [Scaling Guacamole](https://www.scaling-guacamole.com/) - 확장 가능한 엔지니어링과 AI를 활용한 개발·배포 방식에 초점을 맞춘 커뮤니티 학습 콘텐츠입니다.
- [ANZAzureDevs/New-Breakpoint 에피소드 모음](https://github.com/ANZAzureDevs/New-Breakpoint/blob/main/README.md) - 추가 학습과 실용적인 데모를 위한 방송 노트 및 에피소드 링크입니다.

## 계속 연습하기

- 자신의 프로젝트 중 하나에 `copilot-instructions.md`를 작성해 보세요.
- [Copilot CLI](https://docs.github.com/en/copilot/using-github-copilot/using-github-copilot-in-the-command-line)를 사용해 보세요. `gh copilot suggest "undo my last commit but keep the changes"`는 "변경 사항은 유지하면서 마지막 커밋을 취소해 주세요"라는 요청입니다.
- 실제로 만들고 싶은 기능을 대상으로 전체 개발 과정을 다시 진행해 보세요.
